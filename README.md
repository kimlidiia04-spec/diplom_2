Автотесты API Stellar Burgers

Описание проекта

Проект предназначен для автоматизированного тестирования API сервиса Stellar Burgers.

Проверяются эндпоинты создания пользователя, авторизации и создания заказов.

Используемые технологии

Python 3.12

Pytest

Requests

Allure Pytest

GitHub Actions

GitHub Pages

Создание уникального пользователя.

Создание уже зарегистрированного пользователя.

Создание пользователя без обязательного поля.

Структура проекта

tests/ — автотесты.

conftest.py — фикстуры.

data.py — тестовые данные.

helpers.py — вспомогательные функции.

pytest.ini — настройки Pytest.

requirements.txt — зависимости проекта.

.github/workflows/tests.yml — настройки GitHub Actions.

Запуск тестов

Установка зависимостей:

pip install -r requirements.txt

Запуск тестов:

pytest

Запуск с сохранением результатов Allure:

pytest --alluredir=allure-results
